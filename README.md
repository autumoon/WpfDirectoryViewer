# WpfDirectoryViewer

目录结构查看器（WPF .NET 8.0）

本工具用于快速查看、导出目录结构，并提供“反向重建结构”能力：根据由本工具导出的树状文本（.txt）在目标位置重建同名的目录与空文件。

---

## 功能概览

- 目录浏览与展示
  - TreeView 展示所选目录结构。
  - 支持显示文件大小与修改时间（可开关）。
- 导出
  - 支持导出为 TXT / Markdown / HTML 三种格式。
  - TXT 支持“输出形式”二选一：`树形结构`（默认）或 `完整路径`，选择会保存到配置。
  - 文本格式采用树状/完整路径，兼容后续的“反向重建”。
- 反向重建结构（新增）
  - 输入：由本工具导出的 TXT（第一行为绝对路径，后续为树状结构或完整路径列表，自动识别）。
  - 输出：在目标目录下，以根目录名为起点，创建目录与空文件（忽略大小与时间）。
  - 支持 Dry Run 预览。
  - 支持将 .txt 拖放到输入框，自动解析根目录名，并将输出目录默认设为该 .txt 所在目录。
- 托盘集成
  - 程序启动显示托盘图标和一次通知。
  - 托盘菜单项：打开主窗口 / 反向重建结构… / 退出。
  - 点击通知可直接打开“反向重建结构”。
- 多屏与 DPI 适配
  - 主窗口与反向窗口均按当前屏幕 DPI 计算居中。

## 界面与使用

### 主窗口（目录结构查看器）

- 当前目录
  - 点击“浏览…”或将目录拖入文本框以快速选择。
  - 选中目录后，TreeView 显示其结构。
- 输出目录
  - 导出文件将保存到此目录下，文件名使用当前目录名。
- 导出内容开关
  - 显示文件大小 / 显示修改时间。
- 输出形式
  - 树形结构 / 完整路径 二选一，默认树形结构，对 TXT、MD、HTML 三种格式同时生效。
- 导出格式
  - TXT / MD / HTML 可多选。
- 快捷操作
  - 双击窗口空白处触发导出（同“导出”按钮）。

### 反向重建结构窗口

- 输入 TXT
  - 点击“浏览…”选择 TXT，或直接将 .txt 文件拖放到输入框。
  - 选择/拖入后：自动解析根目录名，并将“输出目录”设为该 .txt 所在目录。
- 输出目录
  - 重建结构将创建在“输出目录/根目录名/...”下。
- 仅预览（Dry Run）
  - 仅打印将要创建的路径，不实际执行写入。
- 开始创建
  - 执行目录与空文件的创建。已存在将跳过（幂等）。
- 关闭行为（与主窗口联动）
  - 若打开反向窗口时主窗口被隐藏，则关闭反向窗口后程序会直接退出。
  - 若主窗口未隐藏，则仅关闭反向窗口，不退出程序。

## 导出格式说明（TXT / MD / HTML）

「输出形式」选项对 TXT、MD、HTML 三种格式同时生效：

- 树形结构
  - TXT 使用 `│  `、`├──`、`└──` 连接符。
  - MD 使用缩进列表。
  - HTML 使用缩进的 `<div class='indent'>` 嵌套。
- 完整路径
  - TXT 每行为完整绝对路径。
  - MD 每行为 `- 📁 绝对路径` 或 `- 📄 绝对路径`（无缩进）。
  - HTML 每行为 `<div class='folder'>📁 绝对路径</div>` 或 `<div class='file'>📄 绝对路径</div>`（无 `<div class='indent'>` 嵌套）。
- 所有格式的目录均以 `/` 结尾，文件大小和时间（可选）始终位于括号内。

### TXT 树形结构

- 第一行：根目录的绝对路径，例如：
  ```
  D:\Tools\OtherTools\LoveConfessionWpf
  ```
- 随后的树状结构使用如下字符：`│  `、`├──`、`└──`。
- 目录名以 `/` 结尾作为标记，文件大小和时间（可选）始终位于括号内，示例：
  ```
  ├── music/  (2025-09-09 15:42:18)
  │   ├── 2.follow me.mp3  (2.71 MB, 2012-03-09 17:51:06)
  │   └── 2.Skinnamarink.mp3  (1.29 MB, 2008-06-28 09:00:18)
  └── LoveConfessionWpf.exe  (176.2 KB, 2025-09-09 15:40:30)
  ```

> 反向重建会忽略括号中的大小和时间，仅按名称与层级重建目录与空文件。
> 目录名尾部的 `/` 是目录标记，反向重建会据此将该项创建为目录（可正确识别空目录）。

### 完整路径格式（“输出形式：完整路径”）

- 第一行仍为根目录的绝对路径，后续每行为该项的完整绝对路径。
- 目录以 `/` 结尾，文件大小和时间（可选）仍在括号内，示例：
  ```
  D:\Tools\OtherTools\LoveConfessionWpf
  D:\Tools\OtherTools\LoveConfessionWpf\music/
  D:\Tools\OtherTools\LoveConfessionWpf\music\2.follow me.mp3  (2.71 MB, 2012-03-09 17:51:06)
  D:\Tools\OtherTools\LoveConfessionWpf\LoveConfessionWpf.exe  (176.2 KB, 2025-09-09 15:40:30)
  ```
- 反向重建会自动减去第一行根路径前缀得到相对路径后再重建。
- 兼容旧相对路径格式：若某行不是以根路径开头，会按相对路径处理。
- 反向重建自动识别树形结构与完整路径两种格式（均忽略括号中的大小和时间，目录以尾部 `/` 或 `\` 识别）。

## 反向重建的解析规则

- 自动识别两种格式：TXT 中包含 `├── ` 或 `└── ` 连接符时按树形结构解析，否则按完整路径列表解析。
- 根目录名来自第一行绝对路径的最后一级。
- 完整路径格式解析：每行为完整绝对路径，去除第一行根路径前缀得到相对路径；目录以 `/` 或 `\` 结尾；元数据（大小/时间括号）用正则去除后再识别目录标记；若某行不以根路径开头则按相对路径保留。
- 树形结构层级计算：根据 `│  `/空格缩进与 `├──`/`└──` 的位置计算。
- 目录判断：名称以 `/` 或 `\` 结尾即为目录（新导出格式标记）；旧格式无标记时，若下一行深度大于当前行，当前行为目录，否则为文件。
- 括号信息：仅去除末尾的大小/时间元数据括号（`(大小, 时间)`、`(时间)`、`(大小)`），名称中普通括号不会被误删。

## 注意事项

- 权限
  - 创建目录/文件需要对目标路径有写入权限。
  - 建议避免在系统目录或受限目录执行重建。
- 路径与文件名
  - 重建时若遇到无效字符或权限限制，将跳过并记录日志。
- TXT 格式要求
  - TXT 必须为本工具生成格式（第一行为绝对路径，树状结构使用 `│  `、`├──`、`└──`）。
  - 文件大小和时间若存在，必须在括号内，不会被识别为文件名的一部分。
  - 新导出格式中目录名以 `/` 结尾，空目录可被正确识别并重建；旧格式没有 `/` 标记，空目录无法可靠识别，会被当作空文件创建。
- 幂等性
  - 已存在的目录/文件会跳过，确保可重复执行。
- 托盘与退出
  - 点击主窗口关闭按钮时，窗口隐藏到托盘，程序不退出（托盘图标保持）。
  - 托盘“打开主窗口”可恢复主窗口（若窗口已被关闭则重新创建）。
  - 托盘“退出”真正退出程序。
  - 系统关机/注销时程序不会阻止退出，正常关闭。
  - 从托盘通知或菜单打开反向窗口时，主窗口会被隐藏。此时关闭反向窗口将直接退出程序。
  - 若通过托盘“打开主窗口”恢复主窗口，再关闭反向窗口仅关闭窗口本身。
  - 反向重建窗口为单例：重复打开只激活已有窗口。

## 常见问题（FAQ）

- 托盘图标没有显示？
  - 可能被 Windows 折叠到“隐藏的图标”。可在任务栏设置中将其设为常显。
- 点击通知没有反应？
  - 部分系统环境禁用了气泡通知；可通过托盘右键菜单选择“反向重建结构…”。
- 拖拽 .txt 无法识别？
  - 确认拖入的是 `.txt` 后缀文件。
  - 文件第一行必须是绝对路径，后续树状结构必须使用本工具导出格式。
